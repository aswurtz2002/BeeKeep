# BeeKeep Kotlin v1.1.0

## Smart Seasonal Scheduling
- Added editable seasonal planning templates to Calendar
- Added 90-day, 6-month, and 1-year planning horizons
- Added 7/14/30-day recurring calendar tasks
- Recurring tasks create their next occurrence only when the current task is completed
- Seasonal plan generation is duplicate-safe
- Calendar displays the current planning season
- All scheduling remains local/offline-first and uses the existing reminder system

## Safety / product behavior
- Templates are planning aids, not treatment instructions or diagnoses
- BeeKeep never starts a treatment automatically
- Existing hive, inspection, NFC, camera, GPS, notification, Room, and cloud-sync flows are unchanged
