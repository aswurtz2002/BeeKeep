# BeeKeep Kotlin v1.0.1

Deep regression, reliability, and performance polish after the Smart Inspection Assistant release.

The product surface is unchanged: BeeKeep remains a native Android/Kotlin app with offline-first Room storage, optional Supabase sync, NFC, camera, GPS, voice logging, reminders/calendar, hive timelines, and Smart Inspection recommendations.

This release focuses on preventing new features from interfering with existing ones, especially around concurrent sync, reminder rescheduling, realtime connections, photo memory use, and native camera/NFC lifecycle behavior.
