# BeeKeep Kotlin v0.8.0

## Calendar + reminders
- First-class Calendar bottom tab.
- Month navigation, today shortcut, selected-day agenda, task dots.
- Schedule one-time hive/apiary tasks with date and time.
- Optional reminders stored with each task.
- Android notification permission handling.
- AlarmManager reminder delivery with WorkManager fallback.
- Reminders rescheduled automatically after device reboot.
- Quick templates for common field jobs.
- Overdue and completion states.

## Polish
- Today gets a distinct calendar state.
- Notification permission UI updates immediately after the Android prompt.
- Agenda cards show only relevant task date context and clearer due-time status.

## Next direction
The next feature milestone can build on Calendar with smarter recurring/seasonal task planning and inspection-driven recommendations.
